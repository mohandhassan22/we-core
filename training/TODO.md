# نتائج التنفيذ

- [ ] صفحة عربية RTL باسم **we core trainer** تعرض خمس وحدات تدريبية بألوان الأبيض والموف، وتعمل على الهاتف والكمبيوتر.
- [ ] كل وحدة تعرض شرحًا مبسطًا مستندًا إلى محتوى WE-Core الحالي وتوفر فيديوهات Google Drive أو YouTube داخل الصفحة.
- [ ] اختبار تحديد مستوى أولي يقيّم الموظف ويقترح الوحدة التالية.
- [ ] كل وحدة توفر أسئلة اختيار من متعدد، وتظهر الإجابة الصحيحة وشرحًا مبسطًا بعد الإجابة.
- [ ] طلبات إنشاء الأسئلة والشروحات تمر عبر دالة Supabase `trainer-ai` ولا تكشف أي مفتاح AI في المتصفح.
- [ ] حفظ إكمال الوحدات والدرجات والمحاولات ونسبة التقدم لكل موظف في Supabase.
- [ ] الموظف يرى تقدمه ونتائجه والخطوة التدريبية التالية بعد تسجيل الدخول.
- [ ] مدير الفرع يرى تقدم موظفي فرعه فقط، مع منع قراءة تقدم الفروع الأخرى عبر RLS ودالة التقرير.
- [ ] المشروع يوفر `GET /manus-routes.json` ويبدأ بخادم يستمع على `0.0.0.0:3000`.
